COMMISSIONER TOOLS

Schedule Import

Load a whole season's schedule from a spreadsheet or CSV file. It feeds the Schedule page, the Game of the Week and the week's game previews on the Overview.

01 IMPORT

Import the schedule.

Upload a .csv / .tsv file or paste rows copied from a spreadsheet, including the header row. Check the preview, then import.

LOCAL TO THIS BROWSER

ESPN schedule grid: open espn.com/nfl/schedulegrid, select the whole table from TEAM down to the last team's row, copy, and paste it here. Each cell is that team's opponent ("SEA" = at home, "@LAC" = away) or BYE; both teams' rows are merged into one game.

Or a game list. Columns it understands (any order, extra columns are ignored): Week (1–18, or Wild Card, Divisional, Conference, Super Bowl), Away, Home, Date, Time / Kickoff, Note / TV. Instead of Away and Home you can use one Matchup column like "BUF @ NYJ" or "Bills at Jets". Teams can be abbreviations, nicknames or full names.
